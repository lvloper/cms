# Caso Amnistía Internacional Argentina

Primera especificación de contenido para presentar a Amnistía dentro del portfolio de Socies.

## Dirección del caso

- **Idea principal:** acompañamiento digital continuo.
- **Tono:** cercano, humano y profesional.
- **Formato:** breve, editorial y dominado por imágenes, videos y capturas.
- **Inicio de la relación:** 2018.
- **Rol de Socies:** equipo digital extendido.
- **Evitar:** un caso de estudio largo, demasiada explicación técnica o atribuirnos las campañas y contenidos creados por Amnistía.

## Archivos

1. `01-narrativa.md`: concepto y relato general.
2. `02-flujo-de-bloques.md`: secuencia propuesta para la página.
3. `03-copy.md`: textos breves listos para trabajar.
4. `04-media-inventory.md`: material visual necesario.
5. `05-content-model.md`: estructura de datos para construir el caso con bloques.

## Principio editorial

La página debe alternar dos ideas:

> Lo que Amnistía necesita hacer.

> Cómo Socies hace posible, sostiene o acelera esa tarea.

La tecnología aparece como soporte de la misión, nunca como protagonista aislada.
