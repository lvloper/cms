# Inventario multimedia

## Objetivo

Construir una página con predominio visual y poco texto.

La selección debe mostrar:

- Escala.
- Variedad.
- Evolución.
- Autonomía del cliente.
- Cercanía del acompañamiento.
- Trabajo técnico visible e invisible.

---

# 1. Hero

## Necesarios

- Video de 8 a 15 segundos recorriendo el sitio principal.
- Captura desktop del home.
- Captura mobile.
- Captura de una causa.
- Captura de un formulario.
- Captura del CMS.

## Tratamiento

- Composición editorial.
- Superposición de marcos, sin simular dispositivos en exceso.
- Evitar mockups genéricos.
- Priorizar pantallas reales.

---

# 2. Evolución histórica

## Necesarios

- Sitio anterior a la primera intervención.
- Primera renovación.
- Versiones intermedias.
- Sitio actual.
- Administradores o CMS anteriores.

## Uso

No es necesario construir una línea de tiempo completa. Puede aparecer como una secuencia rápida de cambios.

# 8. Infraestructura y automatizaciones

## Material real posible

- Dashboard de monitoreo.
- Métricas agregadas de tráfico.
- Alertas.
- Estado de servicios.
- Backups.
- Logs anonimizados.
- Diagrama de infraestructura.
- Flujo de Salesforce.
- Flujo de formularios.
- Proceso de generación de certificados.
- Automatizaciones de email.

## Restricciones

- Ocultar credenciales, dominios internos, datos personales e información sensible.
- No mostrar capturas técnicas que no sean comprensibles.
- Redibujar diagramas cuando una captura resulte confusa.
- Usar datos agregados.

---

# 9. Acompañamiento humano

## Material recomendado

- Fotografías de reuniones.
- Capturas de videollamadas, con autorización.
- Talleres o presentaciones.
- Fragmentos anonimizados de conversaciones.
- Documentos de trabajo.
- Tableros.
- Bocetos.
- Personas del equipo de Socies trabajando.

## Objetivo

Evitar que el caso se perciba como una colección fría de interfaces.

# Checklist de producción

- [ ] Capturas desktop en resolución consistente.
- [ ] Capturas mobile en resolución consistente.
- [ ] Videos sin cursor errático.
- [ ] Datos personales ocultos.
- [ ] CMS con contenido real o demostrativo.
- [ ] Métricas verificadas.
- [ ] Logos e identidades usados correctamente.
- [ ] Permisos para testimonios y fotografías.
- [ ] Selección final de 15 a 25 piezas.
- [ ] Optimización WebP, AVIF o MP4 según formato.
